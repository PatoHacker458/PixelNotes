# PixelNotes

PixelNotes es una aplicación de toma de notas para Android enfocada en la productividad estudiantil. Busca fusionar la potente capacidad de dibujo y gestión de trazos de plataformas líderes con la simplicidad y sincronización en la nube de herramientas como Google Keep.

## Características Principales
- **Lienzo de alto rendimiento:** Soporte nativo para lápices ópticos (USI 2.0 y Wacom EMR) con baja latencia y rechazo de palma.
- **Interfaz Moderna:** Diseño adaptativo basado en Material Design 3 (Preparado para Android 17).
- **Gestión Avanzada:** Organización intuitiva por carpetas y cuadrículas.
- **Sincronización en la Nube:** Copias de seguridad automáticas a través de Google Drive API.
- **Exportación:** Generación de documentos PDF de alta calidad manteniendo los trazos vectoriales.

## Tecnologías Utilizadas
- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose
- **Base de Datos Local:** Room (SQLite)
- **Sincronización:** Google Drive REST API
