# 📝 Pixel Notes

Pixel Notes is an Android note-taking application focused on student productivity. It aims to merge the powerful drawing and stroke management capabilities of industry-leading platforms with the simplicity and cloud synchronization of tools like Google Keep.

## 🚀 Key Features (In Development)
- **High-Performance Canvas:** Native support for styluses (USI 2.0 and Wacom EMR) with low latency and palm rejection.
- **Modern Interface:** Adaptive design based on Material Design 3 (Android 17 ready).
- **Advanced Management:** Intuitive organization using folders and grid layouts.
- **Cloud Synchronization:** Automatic backups via Google Drive API.
- **Export Capabilities:** High-quality PDF document generation preserving vector strokes.

## 🛠️ Technologies
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Local Database:** Room (SQLite)
- **Synchronization:** Google Drive REST API
